# Modul Latihan JavaScript

Folder ini berisi contoh latihan mandiri yang dapat dijalankan satu per satu dengan membuka berkas HTML di browser. Materi mengikuti topik JavaScript dasar pada bahan praktikum: variabel dan kondisional, loop dan fungsi, array dan objek, serta DOM dan `localStorage`.

Berkas ini merupakan contoh latihan untuk melengkapi struktur folder; tambahkan atau sesuaikan dengan file latihan asli yang dikerjakan selama sesi praktikum jika ada ketentuan khusus dari pengajar.

1. `01-variabel-kondisional.html` — variabel, if/else, operator ternary, dan switch-case.
2. `02-loop-fungsi.html` — loop, tabel perkalian, faktorial, bilangan prima, dan FizzBuzz.
3. `03-array-objek.html` — array objek mahasiswa, filter nilai, dan pengurutan.
4. `04-dom-localstorage.html` — manipulasi DOM, tambah/hapus tugas, dan penyimpanan lokal.
